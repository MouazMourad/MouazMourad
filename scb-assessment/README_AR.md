# SCB Infrastructure Assessment PWA

تطبيق مستقل باللغة العربية لتقييم البنية التحتية المصرفية بطريقة تعاونية.

- 174 سؤالاً ضمن 17 مجالاً فنياً.
- جرد الأنظمة والخدمات وHA / Cluster / Load Balancer / Backup / DR.
- كتابة الوضع الحالي والملاحظات والتحسينات لكل نقطة.
- تقرير HTML تفصيلي وتصدير / استيراد JSON.
- PWA يعمل دون إنترنت بعد فتحه أول مرة على HTTPS.

## الخصوصية
هذه الملفات تحتوي **التطبيق الفارغ فقط**، وليست فيها أي إجابات أو بيانات مصرفية. مدخلات التقييم تُحفظ في تخزين المتصفح المحلي على الجهاز ولا تُرسل إلى GitHub أو Vercel. لا تدخل كلمات مرور أو عناوين سرية أو بيانات عملاء. احتفظ بنسخة JSON احتياطية آمنة ومنفصلة.

## نشر GitHub Pages
تم تجهيز workflow في `.github/workflows/deploy-scb-assessment.yml`.
من إعدادات المستودع > Pages اختر **GitHub Actions** كمصدر النشر، ثم شغّل `Publish SCB Assessment PWA` من تبويب Actions.

## التثبيت على iPhone
افتح رابط النشر عبر Safari، ثم مشاركة > إضافة إلى الشاشة الرئيسية. افتح التطبيق أول مرة بوجود إنترنت، ثم تحقق من تشغيله في وضع الطيران.
